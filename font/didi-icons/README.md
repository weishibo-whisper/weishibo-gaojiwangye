2. 用图标名（如 `car-line`、`taxi-line`）在站点搜索框检索，或直接在 Remix 图标库中查找。
3. 悬停图标，点击星标 / “收藏” 即可加入自己的收藏夹。

## 本地文件说明

- SVG 已统一处理为 `fill="currentColor"`，可在页面中通过 CSS 的 `color` 改变颜色。
- `manifest.json` 保留了每个图标的原始 ID 与下载接口地址，便于核对。
- 页面内使用内联 SVG symbol，不依赖外部网络，双击 HTML 即可离线打开。
