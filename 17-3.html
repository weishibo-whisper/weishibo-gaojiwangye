列表到详情的请求流程

01

请求列表

GET /products?limit=8 拿到 8 件商品，并保存每件商品的 id。
→
02

点击商品

17-3-detail.html?id=1 把商品 id 通过 URL 查询参数传给详情页。
→
03

请求详情

GET /products/1 详情页读取 id，再请求单个商品并渲染完整信息。

列表页与详情页是两个独立页面，各自发起 fetch 请求。列表页只负责展示摘要和传递 id， 详情页负责根据 id 获取并展示完整商品数据。
