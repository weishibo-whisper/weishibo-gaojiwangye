确认请求方法和接口地址后，点击“发送请求”查看接口返回的数据。

01请求方法

支持 GET、POST、PUT、PATCH、DELETE。GET 不发送请求体，其余方法可携带 JSON 数据。

02响应与错误

成功与失败都会展示状态码；HTTP 错误仍显示响应体，网络或跨域错误会给出原因与排查建议。

03跨域限制

浏览器只能读取接口允许暴露的响应头。被测接口需要支持 CORS，例如 jsonplaceholder.typicode.com。

本页完全使用原生 fetch 实现。POST / PUT / PATCH 的请求体会先做 JSON 格式校验， 通过后才会发送；JSONPlaceholder 是模拟接口，POST 等操作不会真正写入服务器数据。
