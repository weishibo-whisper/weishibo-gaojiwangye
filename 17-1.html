JSON 数据格式

JSON（JavaScript Object Notation）是一种轻量级的文本数据交换格式。 它以“键值对”描述数据，既能被 JavaScript 直接解析，也能被几乎所有后端语言读取， 是前后端接口通信最常用的数据格式。

JSON 语法规则

记住这六条，就能写出和读懂绝大多数接口数据

键必须使用双引号

属性名必须写成 "name"，不能使用单引号，也不能省略引号。

值类型有限

只允许字符串、数字、布尔值、null、对象和数组；没有 undefined、函数和日期对象。

不允许注释

JSON 中不能写 // 或 /* */ 注释，也不能在最后一项后面留下多余逗号。

可以任意嵌套

对象里可以放数组，数组里也可以放对象，从而表达列表、详情等复杂结构。

JSON 是一段字符串

它与对象的外观相似，但本质是文本；传输和存储前必须先用 stringify 转换。

解析要处理异常

格式不正确时 JSON.parse() 会抛出错误，因此应放在 try...catch 中执行。
