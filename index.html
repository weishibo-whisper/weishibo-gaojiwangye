课程亮点

Design System
  • 从基础网页结构开始，逐步掌握文本、列表、图像与布局元素的组合方式。
  • 深入学习 CSS 规则、层叠继承、盒模型和 Flex 弹性布局，提升页面设计能力。
  • 所有作品均使用原生 HTML 与 CSS 编写，没有使用 CDN，保持课程实践的纯原生风格。
